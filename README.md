# Hi, I'm Bruno 👋

I'm a Nutritionist turned Data Scientist, with a Master's in Data Science from Universidad Complutense de Madrid.

My background is in clinical practice and research - four years working as an auxiliary researcher and seeing patients. When I moved into data, health felt like the natural space to work in: I understand the domain, I know what the data represents, and I know what questions are actually worth asking.

I work with Python, SQL, machine learning and data visualization, with a focus on health and clinical datasets. My most recent project is a non-invasive screening tool for fatty liver disease (MASLD) - a deployed ML Web App that estimates liver steatosis from clinical data, built as my Master's thesis.

## Projects
### 🩺 [Cribado No Invasivo de Hígado Graso (MASLD)](https://github.com/BrunoInuggi/cribado-masld)

**Python · Machine Learning · Streamlit**

Herramienta de cribado de esteatosis hepática para la consulta nutricional (TFM). Estima el grado de hígado graso desde variables clínicas usando machine learning sobre datos NHANES, y se despliega como app web. Incluye interpretabilidad (SHAP) y validación clínica.

🔗 [Probar la app](https://cribado-masld-fycc5vku6nsadxrsv5ae88.streamlit.app)

### 🔬 [FDA Adverse Drug Events Analysis](https://github.com/BrunoInuggi/fda-adverse-drug-events-analysis)
**SQL · Snowflake**

Exploratory analysis and pharmacovigilance signal detection on the FDA FAERS dataset. Includes descriptive analysis, PRR and ROR signal detection, and a full EDA across drug-outcome pairs.

---

### 🧹 [Clinical Trial Data Cleaning](https://github.com/BrunoInuggi/clinical-trial-data-cleaning)
**SQL · Snowflake**

End-to-end data cleaning pipeline on a simulated adverse events dataset. Covers referential integrity, logical inconsistencies, dose validation per drug, and null handling — with clinical reasoning behind every decision.

**Python**
